Recomendaciones antes de subirla:
- Comprimir a JPEG u WebP optimizado, idealmente entre 150 y 250 KB, para que cargue rápido en móvil.
- Resolución sugerida: al menos 1920px de ancho para que se vea nítida en pantallas grandes.
- Si en pantallas estrechas el diamante queda cortado de forma rara, se puede añadir además
  "hero-marmol-mobile.png" (un recorte pensado para móvil) y referenciarlo en el media query
  de estilos.css (@media max-width: 600px, dentro de .hero__bg).

Mientras este archivo no exista, el hero usa un degradado de respaldo en tonos dorado/rosa
generado por CSS puro (ver .hero en estilos.css), para que la web no se vea rota.
